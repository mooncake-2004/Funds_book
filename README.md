# Funds_book
# 📒 Funds Book (AI 智能記賬本)

基於 React + TypeScript + AI 的個人多幣種財務系統。支持手機/電腦自適應共通、多幣種匯率換算、拆分記賬與純符號流核算。

---

## 🗺️ 項目文件地圖（忘記時隨時查閱）

### 1. 🛠️ 地基工具組（系統骨架，平時永遠不需要動）
- **`package.json`**：大樓物業清單，記錄項目用了 React 和 Vite 等基礎庫。
- **`vite.config.ts`**：發電機，負責把我們的代碼極速打包成網頁。
- **`index.html`**：大門殼子，瀏覽器打開的第一個 HTML 頁面。
- **`main.tsx`**：總電源插頭，負責把 App 掛載到網頁上。

---

### 2. 📖 規格與 AI 大腦（底層業務邏輯）
- **`types.ts`**：**【核心字典說明書】** 定義一筆賬長什麼樣（金額正負號、匯率、折合HKD、賬戶大類、自定義分類等）。
- **`recordPrompt.ts`**：**【AI 記賬員大腦】** 告訴 AI 如何聽懂人話/小票、提取金額正負號、智能拆分 AA 賬單。

---

### 3. 🎨 界面與組件組（我們日常開發的主戰場）
- **`App.tsx`**：**【主舞台】** 總裝車間，把導航和各個功能頁面組裝在一起。
- **`Navbar.tsx`**：**【導航指示牌】** 
  - 手機端：頂部橫向純文字膠囊導航
  - 電腦端：左側側邊欄（可以在此修改 Logo 和模塊菜單）
- **`Dashboard.tsx`**：**【財務大盤】** 展示總淨資產、收支統計、資產分佈。
- **`AiInput.tsx`**：**【快速輸入框】** 隨口說話或打字記賬的組件。
- **`Settings.tsx`**：**【系統設置】**（下一步即將編寫：自定義分類與賬戶管理）。

---

## 📱 手機 vs 💻 電腦 佈局規則
- **手機端 (< 768px)**：頂部橫排膠囊按鈕，主打隨手記、快速查流水。
- **電腦端 (>= 768px)**：左側固定 220px 側邊欄，主打大盤分析與深度管理。
